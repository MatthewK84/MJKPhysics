# Validation

Validation answers one question for each model: is the implementation computing what its page
says it computes, to a stated tolerance? Checks fall into four levels.

| Level | Compares against | Examples |
|---|---|---|
| Analytic | Closed-form solutions | Free fall, projectile with linear drag, torque-free precession, the intermediate-axis flip, bounce height $`e^2 h`$, sliding on an incline |
| Numerical | Properties every correct method must have | Measured convergence order, energy and angular-momentum drift, unit-norm preservation on SO(3) |
| Published data and reference code | Measurements and independent implementations | UIUC propeller data, the Crazyflie identification, Aerosonde trim and eigenvalues from BYU's reference code, the NTNU Skywalker X8 papers |
| Statistical | Spectra and noise statistics | Turbulence power spectra against the Dryden model, IMU noise recovered from Allan deviation |

Every check reports four things:

- **Tolerance**, and why it suits the step size and model.
- **Result**: the measured error.
- **Pass or fail.**
- **Known limitations**: what the check doesn't cover.

The tables on this page are generated by `mjk validate`, so they always match the code that
produced them. The analytic checks below are the first; the full report is
[#81](https://github.com/MatthewK84/MJKPhysics/issues/81).

## Analytic checks

These checks run the whole simulation loop, `World` with RKMK4 at the default 1 kHz, and compare
it with closed-form solutions ([#16](https://github.com/MatthewK84/MJKPhysics/issues/16)). The
convergence-order checks run every integrator at four step sizes.

Each tolerance is fixed before the run from an error estimate: ten times the estimate, rounded up
to a power of ten. The estimate is printed under the table, so a reader can check that the
tolerance suits the step size. A test fails if any check fails, and CI requires the WebAssembly
build to print the same table byte for byte.

### Closed forms

**Free fall** from rest under standard gravity, Down positive:

```math
z = \tfrac12 g_0 t^2, \qquad v = g_0 t
\qquad\text{(VAL-1)}
```

**A projectile with linear drag** $`-c\,\mathbf{v}`$, with time constant $`\tau = m/c`$ and
terminal velocity $`\mathbf{v}_t = g_0\tau\,\mathbf{z}_W`$, launched from the origin at
$`\mathbf{v}_0`$:

```math
\mathbf{v}(t) = \mathbf{v}_t + (\mathbf{v}_0 - \mathbf{v}_t)\,e^{-t/\tau}
\qquad\text{(VAL-2)}
```

```math
\mathbf{x}(t) = \mathbf{v}_t\,t + \tau\,(\mathbf{v}_0 - \mathbf{v}_t)\left(1 - e^{-t/\tau}\right)
\qquad\text{(VAL-3)}
```

**A torque-free axisymmetric body**, with transverse and axial moments $`I_t`$ and $`I_a`$:
the transverse angular velocity turns in body axes at

```math
\Omega = \frac{(I_a - I_t)\,\omega_3}{I_t}
\qquad\text{(VAL-4)}
```

the symmetry axis turns around the fixed angular momentum $`\mathbf{L}`$ at

```math
\dot\phi = \frac{\lvert\mathbf{L}\rvert}{I_t}
\qquad\text{(VAL-5)}
```

and the attitude, from $`\mathbf{R}_0`$, is a rotation about $`\hat{\mathbf{L}}`$ composed with one
about the body's symmetry axis $`\mathbf{e}_3`$:

```math
\mathbf{R}(t) = \mathrm{Rot}\!\left(\hat{\mathbf{L}},\ \frac{\lvert\mathbf{L}\rvert t}{I_t}\right)\mathbf{R}_0\,\mathrm{Rot}(\mathbf{e}_3,\ -\Omega t)
\qquad\text{(VAL-6)}
```

**A torque-free body spinning near its intermediate axis**, $`I_1 < I_2 < I_3`$, with angular
momentum $`M`$ and kinetic energy $`E`$ such that $`M^2 > 2EI_2`$. The intermediate-axis rate is
proportional to $`\mathrm{sn}(\omega_p t, k)`$ (Landau and Lifshitz, §37), so it changes sign, and
the body flips, every

```math
\Delta t = \frac{2K(k)}{\omega_p}, \quad
\omega_p = \sqrt{\frac{(I_3 - I_2)(M^2 - 2EI_1)}{I_1 I_2 I_3}}, \quad
k^2 = \frac{(I_2 - I_1)(2EI_3 - M^2)}{(I_3 - I_2)(M^2 - 2EI_1)}
\qquad\text{(VAL-7)}
```

with the complete elliptic integral computed by the arithmetic–geometric mean:

```math
K(k) = \frac{\pi}{2\,\mathrm{AGM}\!\left(1, \sqrt{1 - k^2}\right)}
\qquad\text{(VAL-8)}
```

**Convergence order** $`p`$ is the least-squares slope of $`\ln e`$ against $`\ln h`$ over
$`h = 1/16`$ to $`1/128`$ s, where $`e`$ is the error against Eq. (VAL-3) for translation and
Eq. (VAL-6) for rotation:

```math
e \approx C\,h^{p}
\qquad\text{(VAL-9)}
```

### Results

{{#include analytic.md}}

*Generated by `mjk validate analytic`. A test fails if this table no longer matches the code.*

**Every error is at or below its estimate.** For the body-frame precession the estimate is not
only a bound but the error itself: RK4-type methods drop the $`(h\omega)^5/120`$ term of
$`e^{ih\omega}`$ each step, and over 10 000 steps at 9 rad/s that predicts $`4.9\times10^{-10}`$
rad/s, which is what the run shows. The flip-interval estimate is far above the measured
$`7\times10^{-13}`$ because it assumes the invariants drift as much as their own estimate allows;
they drift thousands of times less.

**The checks have teeth.** Tests rerun the physics checks with first-order methods: explicit
Euler fails every group, and semi-implicit Euler fails the drag and precession groups. RK4 passes
free fall, drag and precession, as a fourth-order method should.

### Limitations

- **One method at one step.** The physics checks use RKMK4 at 1 kHz, the configuration a run
  uses; the convergence rows cover the other methods.
- **The flip check compares the period, not the trajectory.** Comparing $`\boldsymbol\omega(t)`$
  with the Jacobi elliptic functions sn, cn and dn throughout would be stronger.
- **No coupling between translation and rotation.** Each check exercises one; the models that
  couple them, rotors and aerodynamics, arrive in M2 and M4 with their own validation.
- **No contact.** Bounce height and sliding on an incline need the contact solver and arrive with
  it ([#55](https://github.com/MatthewK84/MJKPhysics/issues/55)–[#61](https://github.com/MatthewK84/MJKPhysics/issues/61)).

hundreds of random inputs and each edge case deterministically:

| [SO(3) maps](../so3.md) ([#9](https://github.com/MatthewK84/MJKPhysics/issues/9)) | Log inverts Exp for angles from $`10^{-12}`$ rad to just under $`\pi`$; Exp inverts Log and takes the short way; Jacobian identities, and the right Jacobian linearizes Exp; plus and minus invert each other; slerp moves at constant rate; Euler angles round-trip, including at gimbal lock; matrix conversion round-trips and non-rotations are rejected; Jacobian coefficients agree with 40-digit references; the small-angle branches of Exp and Log are accurate to within 2 and 4 ulp |

## How the tests are checked

Two gates in CI measure the tests themselves. Engine line coverage must stay at or above 90 %.
Mutation testing changes the code in small ways and fails if any change goes unnoticed by every
test; no mutant of the engine survives. Both are described on the
[Engineering standards](../engineering-standards.md#testing-the-tests) page.
